Want automatic alerts instead of watching? (Tampermonkey userscript)

A webpage cannot read another site's pages, so this frame can only be looked at. The userscript runs on Eventbrite itself and can check availability properly, with desktop and Telegram notifications.

  1. Install Tampermonkey.
  2. Click Install the userscript and confirm.
  3. Open the booking page. A panel appears bottom-right. Press Start.
Install the userscript Open booking page

Telegram setup: message @BotFather, send /newbot, copy the token; send your bot a message; open api.telegram.org/bot<TOKEN>/getUpdates and copy chat.id. Paste both into the panel's ⚙ settings — never into this public page.
