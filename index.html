Booking Monitor

Checks the LDS Part 2 Exam (Feb 2027) Eventbrite page every 15 seconds and alerts you by desktop notification and Telegram when a ticket can actually be booked.

Live status is in the monitor panel on the Eventbrite page, not here. This page can't read it — different browser origin.

Install

  1. Install Tampermonkey.
  2. Click Install the userscript and confirm.
  3. Open the booking page. The panel appears bottom-right.
  4. Press Start, and leave the tab open.
Install the userscript Open booking page

Telegram (optional)

  1. Message @BotFather, send /newbot, copy the token.
  2. Send your new bot any message.
  3. Open api.telegram.org/bot<TOKEN>/getUpdates and copy chat.id.
  4. Paste both into the panel's ⚙ settings — not into this page.
Never put your bot token on this public page. There is deliberately no field for it. Credentials belong in Tampermonkey storage on your own machine.

Notes

  • Only runs while the browser is open and the machine is awake.
  • Backs off automatically if Eventbrite rate-limits the 15s polling.
  • Alerts only on a verified change to available, once per change.
  • Never buys tickets, never touches CAPTCHA, logins or the queue.
